Privacy Policy

This policy explains how the private Pakde Spill rclone desktop OAuth client accesses and uses Google user data.

1. Scope

The client is a personal utility operated by the Pakde Spill project owner. It connects rclone on the owner's Windows device to the owner's Google Drive for backup, integrity verification, and restore. It is not offered to the general public and does not support third-party accounts.

2. Google data accessed

The client requests the Google Drive scope. This allows it to list files and folders, read file metadata and content, upload backup files, compare hashes, and download files for restore.

Full Drive scope is required because the backup set includes files that the owner uploaded manually before the OAuth client was configured. The rclone remote is operationally pinned to the dedicated Pakde Spill folder, but the OAuth scope itself is broader than that folder.

3. How Google data is used

  • Copy selected Pakde Spill project files to the owner's Google Drive.
  • List and compare backup files, sizes, timestamps, and available checksums.
  • Download selected files when the owner performs a restore.
  • Troubleshoot backup failures initiated by the owner.

Google user data is not used for advertising, profiling, model training, credit decisions, surveillance, or any unrelated purpose.

4. Storage and security

Backup files remain in the owner's Google Drive. OAuth access and refresh tokens are stored locally in the owner's rclone configuration and are excluded from source control. The public website does not receive or store OAuth tokens, Drive file contents, or account credentials.

5. Sharing and transfer

Google user data is not sold, rented, shared with advertisers, or transferred to unrelated third parties. Data is processed only by Google Drive and the locally operated rclone client as necessary to perform the requested backup or restore operation.

6. Retention and deletion

The owner controls the retention and deletion of backup files in Google Drive. Local OAuth credentials can be removed by deleting the rclone remote configuration. Access can also be revoked at any time from the Google Account security settings. Revoking access stops future API calls but does not automatically delete files already stored in Drive.

7. User control

The owner may inspect, download, move, or delete backup files directly in Google Drive; stop scheduled operations; revoke the OAuth grant; rotate the OAuth client; or discontinue the integration completely.

8. Limited Use

The use of information received from Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements.

9. Website hosting data

This policy website is hosted by GitHub Pages. The site itself uses no analytics, advertising trackers, cookies, forms, or JavaScript. GitHub may process visitor information such as IP addresses for security and service operation under the GitHub Privacy Statement.

10. Changes and contact

This policy will be updated before the app materially changes its Google data access or use. Non-sensitive questions may be submitted through the repository's public issue tracker. Do not post credentials, tokens, personal data, or security-sensitive information in a public issue.
