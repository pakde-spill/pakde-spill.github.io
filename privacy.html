Kebijakan Privasi

Kebijakan ini menjelaskan cara OAuth desktop client privat Pakde Spill rclone mengakses dan menggunakan data pengguna Google.

1. Cakupan

Client ini adalah utilitas pribadi yang dioperasikan oleh pemilik proyek Pakde Spill. Client menghubungkan rclone pada perangkat Windows milik pemilik dengan Google Drive milik pemilik untuk keperluan backup, verifikasi integritas, dan pemulihan. Client tidak ditawarkan kepada masyarakat umum dan tidak mendukung akun pihak ketiga.

2. Data Google yang diakses

Client meminta scope Google Drive. Scope ini memungkinkan client melihat daftar file dan folder, membaca metadata dan isi file, mengunggah file backup, membandingkan hash, serta mengunduh file untuk pemulihan.

Scope Drive penuh diperlukan karena kumpulan backup mencakup file yang diunggah secara manual oleh pemilik sebelum OAuth client dikonfigurasi. Secara operasional, remote rclone dibatasi ke folder khusus Pakde Spill, tetapi scope OAuth itu sendiri lebih luas daripada folder tersebut.

3. Cara data Google digunakan

  • Menyalin file proyek Pakde Spill yang dipilih ke Google Drive milik pemilik.
  • Melihat daftar serta membandingkan file backup, ukuran, waktu, dan checksum yang tersedia.
  • Mengunduh file yang dipilih ketika pemilik melakukan pemulihan.
  • Menelusuri penyebab kegagalan backup yang dijalankan oleh pemilik.

Data pengguna Google tidak digunakan untuk iklan, pembuatan profil, pelatihan model, keputusan kredit, pengawasan, atau tujuan lain yang tidak berkaitan dengan fungsi tersebut.

4. Penyimpanan dan keamanan

File backup tetap berada di Google Drive milik pemilik. Access token dan refresh token OAuth disimpan secara lokal di konfigurasi rclone milik pemilik dan dikecualikan dari source control. Situs publik ini tidak menerima atau menyimpan token OAuth, isi file Drive, maupun kredensial akun.

5. Pembagian dan transfer

Data pengguna Google tidak dijual, disewakan, dibagikan kepada pengiklan, ataupun ditransfer kepada pihak ketiga yang tidak berkaitan. Data hanya diproses oleh Google Drive dan client rclone yang dioperasikan secara lokal sejauh diperlukan untuk menjalankan proses backup atau pemulihan yang diminta.

6. Retensi dan penghapusan

Pemilik mengendalikan masa penyimpanan dan penghapusan file backup di Google Drive. Kredensial OAuth lokal dapat dihapus dengan menghapus konfigurasi remote rclone. Akses juga dapat dicabut kapan saja melalui pengaturan keamanan Akun Google. Pencabutan akses menghentikan panggilan API berikutnya, tetapi tidak otomatis menghapus file yang sudah tersimpan di Drive.

7. Kendali pengguna

Pemilik dapat memeriksa, mengunduh, memindahkan, atau menghapus file backup langsung di Google Drive; menghentikan operasi terjadwal; mencabut izin OAuth; merotasi OAuth client; atau menghentikan seluruh integrasi.

8. Penggunaan Terbatas

Penggunaan informasi yang diterima dari Google API mematuhi Google API Services User Data Policy, termasuk persyaratan Limited Use.

9. Data hosting situs

Situs kebijakan ini di-host melalui GitHub Pages. Situs tidak menggunakan analytics, pelacak iklan, cookie, formulir, ataupun JavaScript. GitHub dapat memproses informasi pengunjung seperti alamat IP untuk keamanan dan pengoperasian layanan berdasarkan GitHub Privacy Statement.

10. Perubahan dan kontak

Kebijakan ini akan diperbarui sebelum terjadi perubahan material pada akses atau penggunaan data Google oleh aplikasi. Pertanyaan yang tidak bersifat sensitif dapat dikirim melalui issue tracker publik milik repository. Jangan mengirim kredensial, token, data pribadi, atau informasi sensitif terkait keamanan melalui issue publik.
