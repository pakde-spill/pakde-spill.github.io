Situs informasi OAuth

Satu utilitas kecil dengan tugas yang jelas.

OAuth desktop client Pakde Spill rclone membantu pemilik proyek mencadangkan, memverifikasi, dan memulihkan file proyek antara workspace lokal dan Google Drive milik pemilik.

Baca kebijakan privasi Lihat repository publik

Tujuan

Infrastruktur backup pribadi, bukan produk publik

Client ini dioperasikan untuk proyek privat Pakde Spill. Client ini tidak ditawarkan sebagai layanan login publik, tidak mempunyai pendaftaran pengguna, dan tidak memberi akses ke Google Drive milik orang lain.

Situs publik ini tersedia agar identitas aplikasi, akses yang diminta, dan cara penggunaan datanya dapat diperiksa sebelum otorisasi diberikan.

01

Otorisasi

Pemilik memberi izin akses kepada desktop client melalui layar persetujuan OAuth Google.

02

Transfer

rclone menyalin folder proyek yang dipilih ke folder khusus Pakde Spill di Google Drive milik pemilik.

03

Verifikasi dan pemulihan

Checksum memastikan integritas backup, kemudian file dapat dipulihkan ketika perangkat diganti atau data hilang.

Batas publik

Situs ini tidak pernah menangani data Drive

Token OAuth tetap berada dalam konfigurasi rclone lokal milik pemilik. File backup tetap berada di Google Drive milik pemilik. Situs statis ini tidak memiliki login, formulir, analytics, iklan, cookie, ataupun backend aplikasi.
