OAuth information site

A small utility with one clear job.

The Pakde Spill rclone desktop OAuth client helps the project owner back up, verify, and restore project files between a local workspace and the owner's Google Drive.

Read the privacy policy View the public repository

Purpose

Personal backup infrastructure, not a public product

This client is operated for the private Pakde Spill project. It is not offered as a public sign-in service, has no user registration, and does not provide access to anyone else's Google Drive.

The public website exists so the app's identity, requested access, and data practices are visible before authorization.

01

Authorize

The owner grants the desktop client access through Google's OAuth consent screen.

02

Transfer

rclone copies selected project folders to the owner's dedicated Pakde Spill folder in Google Drive.

03

Verify and restore

Checksums confirm backup integrity, and files can be restored when a device is replaced or data is lost.

Public boundary

This website never handles Drive data

OAuth tokens remain in the owner's local rclone configuration. Backup files remain in the owner's Google Drive. This static site contains no login, form, analytics, advertising, cookies, or application backend.
